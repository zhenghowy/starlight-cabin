# 修行时间

这是按仓库最新网页和安卓功能重做的微信小程序，不是把网页放进 `web-view`。旧的接口测试号 `wxa93871210ae14151` 没有沿用。本目录的 AppID 是个人主体小程序「修行时间」：`wx68ff89d7295d60ce`。

仓库里没有旧小程序源码。当前网页说明原来的小程序只剩三间屋子。这一版补上了现在的营地、正负松果、杂货铺、岁月年轮、账号隔离、本机保存、同步状态、冲突保留和排行快照。网页和安卓安装包的行为没有改。服务端也没有改：仍然用原来的登录 Cookie 和 `/api/sync`。

## 和安卓的差别

安卓用 WorkManager 大约每 7 天在后台同步。个人主体小程序的周期性更新只能配置云开发环境，不能配置自己的 HTTPS 地址，而且微信大约每 12 小时才拉一次、也不保证准时。所以这里不做后台每周同步。

打开小程序时，如果距离上次成功同步已经满 7 天并且有网络，会补一次同步。平时打开只读手机里的记录。营地页可以「立即同步」，能看到上次成功时间、未同步条数、错误和冲突。

## 导入

不要把这些文件拷进现在已经打开的旧项目目录。

1. 解压交付的 zip。进入里面带 `project.config.json` 的目录。
2. 打开微信开发者工具，使用「修行时间」管理员微信。
3. 选择「导入项目」，目录选上一步那个文件夹。AppID 保持 `wx68ff89d7295d60ce`，不要改成测试号。
4. 项目设置里 `urlCheck` 是打开的。要在工具里连当前 `https://starlight-cabin-howy.fly.dev` 调试时，到「详情 → 本地设置」，勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。这只影响开发者工具，以及手机上打开调试时。体验版、正式版和关掉调试的手机仍会校验域名。勾上它不等于可以发布。
5. 第一次登录需要网络。密码不会保存。默认接口是线上服务，登录会读写线上存档。调试请使用你自己准备的测试林间名字，不要拿正在使用的正式账号试。

基础库按 3.5.5 填写。日期按北京时间手算，不使用手机上可能没有的 `Intl`。微信客户端过旧时请升级微信。升级这个小程序不用清除数据，原来的 `cabin-state` 和未同步记录会留着。

## 发布前要你在后台做的事

1. 等小程序备案审核通过。未备案时发布会失败，官方返回 `errcode` 86369，`errmsg` 为「小程序上架需先完成备案」。文档：<https://developers.weixin.qq.com/miniprogram/product/record/record_faq.html>
2. 准备一个你自己持有、并且已经完成 ICP 备案的 HTTPS 域名，让它指向上面的现有服务。然后把 `config.js` 里的 `API_ORIGIN` 改成 `https://你的域名`，不要带端口，也不要写成 `https://你的域名:443`。
3. 登录 <https://mp.weixin.qq.com>，进入「开发 → 开发管理 → 开发设置 → 服务器域名」，在 request 合法域名里添加这个域名。域名必须备案，不能填 IP、localhost 或父域名。文档：<https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html>
4. 不要把 AppSecret 写进小程序，也不要发在聊天里。这个客户端不用 `wx.login`，所以不需要 AppSecret。
5. 上传代码、提交审核和发布请在你的微信后台手动做。审核测试账号如果被要求填写，用测试林间名字，不要用正式账号。

## 现在还不能直接上线的原因

`starlight-cabin-howy.fly.dev` 是 Fly.io 的共享域名。微信要求 request 合法域名经过 ICP 备案，接口也会返回 `no_icp_domain`。你无法替 `fly.dev` 做备案，所以正式版不能把现在这个地址配进服务器域名。开发工具里不校验域名，不能代替这一步。

小程序备案仍在平台审核中，审核通过前也不能发布。

个人主体暂不支持微信认证，也不能开通微信支付。杂货铺只是把松果换成现实里的奖励，没有支付。

个人主体「工具 / 记账」的类目说明是消费记录一类的模板工具，并写明不包含用户自定义内容的记录和分享，建议去掉。自定义小事、心愿，以及排行里看到朋友已完成的小事名称，可能被审核认为超出这个说明。「工具 / 日历」可以对应打卡墙。如果审核要求，再决定是否隐藏排行里的小事名称。类目表：<https://developers.weixin.qq.com/miniprogram/product/material/>
